# Version and data availability

Version 1.0.1 contains the R scripts, research manuscript, five original figures, source notes, saved numerical results, and verification code. It includes a copyedit of the first release, with no changes to the empirical tables, R analysis, or saved results. The manuscript originates from ECO 402 in Spring 2026; the public repository edition is dated September 9, 2026.

The `v1.0.1` release identifies this version of the work; `v1.0.0` remains available as the first publication. Use [CITATION.cff](../CITATION.cff) when citing it, and identify a commit or release when discussing specific code or results. A version tag is not a DOI or evidence of peer review.

Raw Bloomberg exports, classroom handouts, textbook PDFs, local run output, and personal settings are excluded. The source-data manifest identifies the original files by checksum. Reproducing the regressions requires those same inputs; a fresh clone alone is not sufficient. No replacement data or artificial sample is presented as the original research data.

The automated repository check validates file links, reference-output integrity, manuscript contents, and the absence of excluded raw files. The separately documented local R run checks the numerical reproduction. The repository check does not claim to rerun the private data on GitHub.

No blanket redistribution license is assigned to third-party materials. No software license has been selected on the author's behalf.
